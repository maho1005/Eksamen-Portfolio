Tema 2

HTML · CSS · Flexbox · Responsive Design

Om temaet

I Tema 2 arbejdede jeg med grundlæggende webudvikling, hvor jeg lærte at lave hjemmesider i HTML og CSS. Jeg arbejdede blandt andet med HTML, CSS, Grid, Flexbox, media queries og responsive layouts, så hjemmesiderne kunne fungere på forskellige skærmstørrelser.

Vi lærte også om designprincipper som kontrast, typografi, visuelt hierarki og brugeroplevelse, og hvordan de kan bruges til at gøre en hjemmeside mere overskuelig og brugervenlig. Derudover blev jeg introduceret til Git og GitHub, debugging og browserens Inspector, som hjalp med at finde og rette fejl i koden. Vi arbejdede også med ophavsret og copyright, så jeg fik en forståelse for, hvordan man må bruge billeder og andet indhold på nettet.

Værktøjer

Website-opgave

Som en del af Tema 2 arbejdede jeg med en website-opgave, hvor jeg skulle udvikle et responsivt website ud fra et udleveret wireframe og layoutdiagram. Selvom grundopsætningen var den samme for alle, skulle jeg selv designe hjemmesidens visuelle udtryk. Her arbejdede jeg blandt andet med gestaltprincipper, brugeroplevelse og mobile-first-metoden for at skabe et overskueligt og brugervenligt design.

Jeg lærte at bruge Grid, Flexbox og media queries til at opbygge responsive layouts, der fungerer på både mobil og desktop. Samtidig arbejdede jeg med designteori, herunder valg af farver, typografi, spacing og visuelt hierarki. Derudover fik jeg erfaring med korrekt filstruktur og organisering af projektets filer, så hjemmesiden blev nemmere at arbejde med og vedligeholde.

Jeg lærte også at arbejde med forskellige billedformater som WebP, PNG, JPEG og SVG. Det gav mig en forståelse for, hvordan valg af billedformat kan have betydning for både kvaliteten af billederne og hjemmesidens performance.

I opgaven arbejdede jeg blandt andet med:

  • Grid og Flexbox
  • media queries
  • navigation
  • responsivt design
  • typografi og farver
  • validering af HTML og CSS
  • deployment via GitHub Pages

Refleksion

I tema 2 lærte jeg, hvordan man opbygger hjemmesider ved brug af HTML og CSS. Jeg blev bedre til at arbejde med responsive layouts og lærte, hvordan Grid, Flexbox og media queries kan bruges til at tilpasse et website til forskellige skærmstørrelser. Jeg havde især udfordringer med at få Grid til at fungere korrekt i starten, men gennem opgaven fik jeg en bedre forståelse for, hvordan man opbygger layouts.

Samtidig lærte jeg, hvordan designvalg som typografi, farver, spacing og visuelt hierarki har betydning for brugeroplevelsen. Derudover fik jeg erfaring med Git og GitHub, debugging og browserens Inspector, som gjorde det lettere at finde og rette fejl i koden. Alt i alt har temaet givet mig et solidt fundament inden for webudvikling, som jeg kan bygge videre på i de kommende projekter.
